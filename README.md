# Advertising Data Insights Dashboard

## Task 2: Social Media Campaign Performance Tracker

**Objective:**  
Analyze ad campaign data (Facebook/Instagram) to evaluate performance, engagement, CTR & ROI.

**Skills Gained:**  
- Marketing analytics  
- Campaign optimization  
- Dashboard storytelling

**Tools Used:**  
- Power BI  
- Google Looker Studio  
- Excel/Sheets  
- Canva (optional)

**Dataset:**  
- Social Media Ads – Kaggle (Click Prediction)  
- Columns include: TV, Billboards, Google_Ads, Social_Media, Influencer_Marketing, Affiliate_Marketing, Product_Sold

**Deliverables:**  
- Polished Power BI dashboard or Google Looker Studio report showing:  
  - Overview of campaign KPIs  
  - Insights into top-performing posts  
  - ROI summary  
  - Interactive filters (by age, region, device, etc.)  
  - Actionable recommendations

**Getting Started:**  
1. Download the dataset from Kaggle.  
2. Open Power BI Desktop and import the CSV.  
3. Clean and transform data in Power Query.  
4. Create measures and KPIs.  
5. Build visualizations and dashboard.  
6. Publish or save `.pbix` file.
